# Image SVG Studio

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**Image SVG Studio** is an open-source desktop editor focused on importing raster images, extracting visual objects, editing masks/layers and exporting faithful SVG/PNG content.

Stack: **Go + Wails + Fabric.js + Vite**. Current target: **Windows x64**.

The repository is being finalized automatically. The bootstrap workflow publishes the complete v0.2.10 source tree and creates the first Windows release with downloadable EXE/ZIP assets.
